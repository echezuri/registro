# Registro

Página web para grabar audio o video desde el teléfono. Al decir **"enviar a <nombre>"**, la grabación termina y queda lista para mandarla por WhatsApp a ese contacto.

- Funciona en Chrome (Android o PC). El micrófono, la cámara y el reconocimiento de voz los da el propio navegador.
- Los contactos se guardan solo en el navegador de cada persona.
- En el teléfono, el botón verde abre el menú "Compartir": se elige WhatsApp y después la persona.
- En PC, el botón descarga el archivo y abre el chat en WhatsApp Web para adjuntarlo.
- Para probar sin hablar, agrega `?demo` a la dirección: aparece un campo para escribir la frase.

Grabar a otras personas sin su consentimiento puede ser ilegal en tu país.
